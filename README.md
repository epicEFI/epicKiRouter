## What EpicRouter is

EpicRouter is a fork and ground-up rewrite of [Freerouting](https://github.com/freerouting/freerouting), the advanced PCB autorouter compatible with any PCB design software that supports the standard Specctra or Electra DSN interface. It imports `.dsn` files generated by the host system's Specctra interface and exports `.ses` Specctra session files — the workflow Freerouting users know, unchanged.

- **The engine is Rust.** The Java engine of Freerouting (the post-2026-refactor codebase) served as the frozen parity oracle through the rewrite milestones M0–M10; at M10 the Java tree was sunsetted — it lives on in git history and upstream at `freerouting/freerouting` (post-refactor tag `post-refactor-2026`).
- **Parity is recorded, not claimed.** Engine behavior is pinned against committed golden baselines captured from the Java oracle before the sunset (corpus, DSN/SES compares, events goldens; see `rust/harness/`).
- **Determinism by construction.** Threads-invariance and deterministic reruns are engine-level guarantees; a board routes to the same bytes under any thread count.
- **Zero-regression discipline.** Every milestone ran a full-comparison battery against the Java oracle goldens; the census ledger and the honest deviations tables live in the milestone plans under `docs/superpowers/plans/`.

## Getting started

### Build from source

Requirements: a Rust toolchain (pinned 1.93), a C compiler toolchain for linking; no Java runtime needed.

```bash
cd rust
cargo build --release -p epic-cli
```

### Route a board (CLI)

DSN in, SES out — the same face Freerouting's CLI users know:

```bash
./target/release/epic-cli route -de MyBoard.dsn -do MyBoard.ses
```

`-de` loads the Specctra design file; `-do` writes the Specctra session file after routing. `epic-cli` with no arguments (or `--help`) prints the full flag surface (settings flags layered defaults → DSN → CLI).

### The GUI

EpicRouter ships an egui desktop shell:

```bash
cd rust
cargo run -p epic-gui --features desktop
```

Load a `.dsn`, autoroute with live progress and a cancel face, export `.ses` — the load → route → export workflow carries over from Freerouting.

## For Freerouting users

EpicRouter keeps the Specctra DSN/SES interchange and the `-de`/`-do` CLI face. Differences at 2.0 are documented in the [migration guide](docs/migration-guide.md) — including the deterministic-budget faces (a wall-clock budget stops the router AT the budget on the identical final board), one route per Session, and the cancel final-state semantics (CANCELLED when the cancel lands mid-routing; COMPLETED — with the routed board exported — when it lands mid-optimization).
